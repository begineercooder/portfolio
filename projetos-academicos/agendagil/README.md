# 📅 AgendAgil

> Sistema de agendamento para personal trainers autônomos que atendem em várias academias.

**Disciplina:** Engenharia de Software — ADS / CEUB
**Tipo:** Projeto em grupo
**Status:** 🟡 Em andamento

## 🎯 Problema

Personal trainers que atuam em mais de uma academia têm dificuldade para organizar horários, evitar conflitos de agenda e controlar os atendimentos dos alunos.

## 💡 Solução proposta

Uma aplicação centralizada onde o personal gerencia sua agenda em todas as academias e os alunos agendam e acompanham suas aulas.
