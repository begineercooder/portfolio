# 🗄️ Banco de Dados I

> Exercícios de modelagem de dados e consultas SQL desenvolvidos na disciplina Banco de Dados I.

**Disciplina:** Banco de Dados I — ADS / CEUB
**Status:** 🟡 Em andamento

## 📚 Conteúdo

| Pasta/Arquivo | Descrição |
|---|---|
| `modelagem/` | Modelos conceituais e lógicos (DER) |
| `scripts/` | Scripts SQL de criação de tabelas e consultas |

## ▶️ Como usar

1. Abra o script desejado da pasta `scripts/` no seu SGBD (ex.: MySQL Workbench).
2. Execute primeiro os scripts de criação (`CREATE TABLE`) e depois os de consulta.

## 🛠️ Tecnologias

- SQL
- SGBD utilizado em aula
