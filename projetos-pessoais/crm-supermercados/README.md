# 🛒 CRM para Supermercados

> Produto SaaS de CRM voltado para redes de supermercados de médio porte no Brasil.

**Tipo:** Projeto pessoal / empreendedor
**Status:** 🟡 Em desenvolvimento

## 🎯 Problema

Redes de supermercados de médio porte têm pouca ferramenta acessível para prever falta de produtos (ruptura de estoque), planejar compras e se relacionar com clientes.

## 💡 Funcionalidades planejadas

- Previsão de ruptura de estoque a partir dos dados do ERP
- Sugestão de compras considerando sazonalidade de preços
- Painéis de acompanhamento para a equipe de compras

## 🧪 Laboratório real

O projeto é desenvolvido e validado na operação de uma rede de supermercados familiar, usando dados reais do dia a dia.
