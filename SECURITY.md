# Política de Segurança – PortfolioHUB

## Versões suportadas

| Versão | Suportada |
| ------ | --------- |
| 2.0    | ✅ Sim    |
| 1.1    | ❌ Não    |
| 1.0    | ❌ Não    |

## Como reportar uma vulnerabilidade

Se você encontrar uma falha de segurança neste repositório, **não abra uma Issue pública**.

1. Acesse a aba **Security → Report a vulnerability** deste repositório; ou
2. Envie um e-mail para **gilmar.carvalho@sempreceub.com.br** com o assunto "Segurança – PortfolioHUB".

Inclua uma descrição do problema, os passos para reproduzir e o impacto possível.

## Prazo de resposta

- Confirmação de recebimento: até **3 dias úteis**
- Avaliação e correção: conforme a gravidade do problema

## Boas práticas adotadas

- Autenticação em dois fatores (2FA) na conta do mantenedor
- Proteção da branch `main` (alterações somente via Pull Request)
- Dependabot e Secret Scanning ativados
- Colaboradores com o menor nível de permissão necessário
- Arquivos sensíveis bloqueados pelo `.gitignore`
- Site publicado com HTTPS obrigatório (GitHub Pages)
