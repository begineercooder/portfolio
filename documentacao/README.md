|---|---|

## 🔀 Fluxo de versionamento utilizado

```
Working Directory  →  git add  →  Staging Area  →  git commit  →  Repositório Local
                                                                        │
                                                          git push ▼    ▲ git pull
                                                                        │
                                                                Repositório Remoto (GitHub)
```

## 🤝 Boas práticas de colaboração

- Criar uma **branch** para cada nova funcionalidade (`git checkout -b nome-da-branch`)
- Abrir um **Pull Request** para revisão antes de juntar na `main`
- Escrever mensagens de commit claras e curtas
- Usar **tags** para marcar versões (`v1.0`, `v1.1`...)
