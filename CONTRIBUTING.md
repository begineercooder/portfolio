# Como contribuir – PortfolioHUB

Obrigado pelo interesse em contribuir! Siga as regras abaixo.

## Fluxo de colaboração

1. Crie uma branch a partir da `main`:
   git checkout -b feat/nome-da-melhoria
2. Faça as alterações e os commits.
3. Envie a branch: git push origin feat/nome-da-melhoria
4. Abra um **Pull Request** para a `main`.
5. Aguarde a revisão. O merge só é feito após aprovação.

> A branch `main` é protegida: não é permitido push direto.

## Nomes de branch

- `feat/` – nova funcionalidade
- `fix/` – correção de erro
- `docs/` – documentação

## Padrão de commits

- `feat:` nova funcionalidade
- `fix:` correção
- `docs:` documentação
- `style:` ajustes visuais

Exemplo: `docs: adiciona guia de contribuição`

## Issues

Use a aba **Issues** para relatar erros ou sugerir melhorias, com título claro e descrição do problema.

## Segurança

Falhas de segurança **não** devem ser abertas como Issue. Siga o arquivo [SECURITY.md](SECURITY.md).
